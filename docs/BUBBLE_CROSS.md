# Step 5-F — Bubble Radar 교차 분석 패널

`kiwoom_collector.bubble_cross`는 Step 5-E에서 저장한 독립 JSON으로 Bubble Radar 타임라인과 종목 검토 패널을 생성한다. 운영 DB, 인증정보, 네트워크를 사용하지 않는다. 기존 Radar v2/v3, sector_bubble, bubble_timeline, bubble_layout 및 두 수집기는 수정하지 않는다.

## 화면 및 정책

- 기존 TOP3 집중 버블과 TOP2 요약, 관심도 색상, TOP20 고유 관심 종목 수에 따른 면적, 시간 선택 기능을 재사용한다.
- 섹터 라벨/버블/전체 목록을 선택하면 오른쪽 핵심 종목 패널이 같은 섹터로 바뀐다. 모바일은 TOP3·버블·핵심 종목 순서다.
- 핵심 카드는 현재 TOP5이면서 0186 40위·잠정 금액 조건을 만족하는 종목이다. 그 외 TOP20 종목은 보조 관찰/필터 제외/코드 검토 펼침에 유지한다. 섹터 탐지 표본은 금액 필터로 줄이지 않는다.
- 정렬은 TOP5 여부, 당일 TOP5 출현, 직전 TOP5 유지, 0186 순위, 현재 관심순위·코드의 사전식 기준이다. 복합 점수·가중치는 없다. 원문 잠정 등락률을 표시하지만 시점 미검증인 섹터 동반 상승을 추정하지 않는다.
- 기본 금액은 1,000억원, 보조는 500억원이다. 이 필터는 명세상 단위로 환산한 **장중 잠정 값**에 적용한다. **장 마감 누적 1,000억원 충족 여부는 미확인**이다.
- 억원/조원 표시를 사용한다. 시총 자료가 없으므로 3,000억원 충족 여부도 미확인이다. 금액·원문 등락률은 임의로 검증 완료에 올리지 않는다.
- `candidate_confirmed=false`와 검증 보류를 유지한다. 매매·주문 기능은 없다.

## 시간·환경·누락

cross_adapter의 300초 잠정 기준을 사용한다. 같은 회차 ID에 연결됐더라도 300초를 넘거나 시각을 확인할 수 없으면 현재 교차 금액을 표시하지 않는다. 수집 시차 통과는 시장 기준 시각·HTS 실측 단위·시장 조건의 검증 완료를 뜻하지 않는다.

과거 회차에는 뒤늦게 받은 다른 회차의 0186 금액·등락률을 소급 표시하지 않는다. 해당 회차의 0198 관심 순위와 당시까지의 TOP5 반복 횟수는 유지하고 교차 자료 없음으로 표시한다. 선택 회차/결합 대상/0186 요청·응답 시각과 UUID는 펼친 근거에서 구분한다.

mock/real 혼합은 거부한다. 운영 0198과 테스트 0186의 구분은 그대로 보존하며 진단 전용 연결로 표시한다. 코드 검토 중이거나 금액이 없는 종목을 0원으로 채우지 않는다. 미분류는 별도 선택 항목으로 유지한다.

TOP3에 상위 산업과 세부 테마가 함께 나오면 기존 태그를 바꾸거나 합치지 않는다. 기존 TOP3 중복 코드 안내를 관찰 정보로 유지한다. 섹터 수 합계가 전체 고유 종목 수보다 클 수 있다.

## 사용

```powershell
python -B -m kiwoom_collector.bubble_cross --input-json saved-adapter-input.json --output new-bubble-cross.html
```

입력은 `cross_adapter.adapt`의 독립 JSON 계약이다. `tests/fixtures/cross_analysis_synthetic.json`과 테스트의 source()는 합성 테스트용 변환 예다. 새 HTML 경로만 허용하며 기존 파일을 덮어쓰지 않는다. 출력은 외부 스크립트·폰트·통신 없이 CSS 라디오/iframe으로 동작하는 로컬 HTML이다.

최신 브라우저의 CSS `:has()` 지원이 필요하다. 긴 이름은 줄바꿈하며 카드·패널은 최소 너비 제약으로 가로 넘침을 방지한다. 모바일에서는 페이지 안의 타임라인 iframe을 세로로 스크롤해 패널을 확인한다.

## 검증과 보존

단위 테스트: 금액 포맷, 입력 무변경, 버블 geometry 유지, 환경 차단, 300초 초과 차단, 과거 금액 소급 금지, 미확인 항목, 출력 경로 보호 및 HTML escaping.

실제 headless 브라우저 테스트: PC 1360×900/모바일 390×844의 섹터 선택·금액 필터·타임라인 전환·미분류·긴 이름·가로 넘침. 기존 전체 회귀와 함께 실행한다. 전체 회귀는 별도 소스 복사본·임시 DB에서 운영 DB/.env 접근 및 외부 네트워크를 차단한다. 브라우저 검증에는 소유한 headless 세션의 localhost 통신만 사용한다.

생성 HTML, PNG, JSON 원본 데이터, 테스트 로그, SQLite/WAL/SHM, 인증서, .env 및 임시 검증 디렉터리는 `data/` 또는 별도 무시 경로에만 보존하며 Git에 포함하지 않는다. 공개 코드 근거 레지스트리와 합성 fixture는 소스 의존성으로 관리한다.
