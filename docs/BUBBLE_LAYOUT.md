# Bubble Radar 반응형 배치 최적화 (Step 4-E)

기존 v2·v3·Bubble v1·Step 4-D 분석을 그대로 사용하고 표시 계층만 확장한다. 메인은 관심섹터 TOP3만 표시하며 TOP2와 대표 종목을 우선 강조한다. 새 출력은 별도 모듈로 생성하고 기존 Step 4-D 명령의 기본 HTML은 유지한다.

```powershell
python -B -m kiwoom_collector.bubble_layout --date 2026-10-20 --environment mock --db data/stock1.db --output data/bubble-layout-20261020-new.html
python -B -m kiwoom_collector.bubble_layout --date 2026-10-26 --environment mock --db data/stock1.db --output data/bubble-layout-20261026-new.html
```

## 변경 범위

`bubble_timeline.render()`에 선택적인 `frame_renderer` 인자만 추가했다. 기본값은 기존 렌더러다. 새 `bubble_layout`은 기존 report 결과의 표시 사전과 SVG 좌표만 복사·변경한다. 회차 선택·정렬·관측 간격·TOP20/TOP5·색상 판정·지속성·진입/유지/이탈·시세·금액 검증·분류 결과를 다시 정의하지 않는다. 분석 객체와 섹터 구성·순서·상태는 원본과 동일하다.

운영 DB는 기존 Step 4-D의 mode=ro + query_only + 읽기 트랜잭션·SQLite Backup API 경로로만 읽는다. API·OAuth·수집 엔진·일정·설정·스키마·분류 importer는 호출하거나 변경하지 않는다. 생성물은 새 파일로 저장하며 기존 파일·심볼릭 링크를 덮어쓰지 않는다.

## 배치와 선택

- PC·모바일 모두 관심도 TOP3까지만 표시한다. v2/v3의 `interest_key`를 재사용하여 TOP20 수→TOP5→TOP10→섹터명 순으로 선택한다. 거래대금·시총·임의 가중 점수는 쓰지 않는다. 전체 분석·기존 모델의 구성과 순서는 보존하고 메인 표시용 TOP3만 별도 계산한다.
- TOP1·TOP2는 두 개의 요약 카드, '우선' 표식과 선 강조로 먼저 읽게 한다. 카드를 누르면 대표 종목과 상세 근거가 열린다. TOP3는 '보조' 표식과 대표 종목 한 줄을 제공한다. TOP2를 크게 만들거나 TOP3를 작게 만드는 가중치는 없으며 같은 수치는 같은 원 면적이다. 최초 상세 선택도 기존 관심도 정렬의 1위로 맞춘다.
- 하루 최대 표시 수에 맞춘 1·2·3칸 격자다. PC는 한 줄, 모바일의 3개는 위 2개·아래 중앙 1개로 배치한다. 초기 PC 상위 섹터는 중앙부터, 모바일 TOP2는 윗줄부터 배치한다. 회차 전환 시 계속 표시되는 섹터의 셀을 유지하고 재등장 시 이전 셀이 비어 있으면 재사용한다. 순위 변화는 표식·카드에 즉시 반영하되 이를 위해 기존 원을 이동시키지 않는다.
- 지도 용량을 당일 전체 프레임 기준으로 고정한다. 일부 빈 칸은 안정성을 위해 남긴다. TOP3 경계를 넘나들면 일부 섹터가 접힌 목록으로 이동할 수 있지만 분석 데이터는 삭제하지 않는다. 지도 밖 섹터·현재 이탈·이전 회차에만 등장한 섹터도 전체 목록에서 선택해 같은 상세를 볼 수 있다.
- 각 화면 유형에 하루 공통 축척을 사용하고 r=k√n을 유지한다. 실제 원 면적은 현재 TOP20 고유 종목 수에 비례하며 지속성·색상·가중치를 섞지 않는다. 값이 같은 원은 같은 크기이고 같은 HTML 안의 시간 전환에서도 같다. PC와 모바일은 별도 축척이다.
- 셀 크기와 여백으로 원 및 클릭 영역이 컨테이너 안에 들어가고 겹치지 않게 한다. 작은 원도 투명한 label 영역을 확보한다. 최소 클릭 반경은 SVG 36단위이며 320px·390px·1360px 검증에서 실제 클릭 지름 44px 이상을 확인한다. 시각적 면적을 확대해 값을 왜곡하지 않는다.
- 공간이 매우 작은 원의 이름은 원 아래에 표시하고, 긴 이름은 명시적 줄임표로 줄인다. 전체 이름은 툴팁·선택 목록·접근성 이름·상세에 남는다. 종목 수는 생략하지 않는다. 새 섹터 표시는 별도 작은 표식이다.

## 화면 사용

PC에서는 버블맵을 주 영역으로 두고 우측의 신규·이탈·반복 및 상세를 유지한다. TOP3에 같은 종목이 중복 소속되면 별도 접힌 안내에 섹터 쌍과 코드·이름을 표시한다. 대분류·세부 분류를 자동 통합하거나 중복을 이유로 섹터를 순위에서 제외하지 않는다. 긴 읽는 법·면적/배치 설명과 전체 목록도 네이티브 details로 접을 수 있다. Bubble/v3 표/함께 보기, 시간 선택·최신 기본 선택·감소/비교 불가·미분류 안내와 모든 원본 진단은 보존한다.

모바일은 상단 회차 요약을 2×2로 압축하고 설명은 접는다. 시간 바는 줄바꿈한다. TOP2 카드와 TOP3 원을 보여주고 버블 아래에 상세 패널과 교체/반복 요약을 둔다. '선택 섹터 상세로 이동'은 srcdoc 문서 안의 `about:srcdoc#selected-detail`로 이동하므로 페이지를 새로 열거나 자료를 다시 조회하지 않는다. 목록의 선택 영역도 최소 높이 44px이다. 모바일 v3 표는 셀을 줄바꿈하여 본문 가로 넘침을 막고 기존 열과 상세는 유지한다.

외부 서버·스크립트·CDN을 추가하지 않는다. 기존 CSP와 sandbox, 전환 효과 끄기·prefers-reduced-motion을 유지한다. 동작은 HTML radio/label·CSS·네이티브 details와 내부 링크로 이뤄진다.
