# Sector Bubble Radar v1

Radar v3의 분석 결과를 SVG 버블맵으로 표현하는 별도 읽기 전용 모듈이다. v2·v3 코드와 기존 CLI를 그대로 보존한다. 외부 디자인·라이브러리·서버·CDN 없이 로컬 HTML만으로 작동한다.

```powershell
python -B -m kiwoom_collector.sector_bubble --date 2026-10-20 --environment mock --db data/stock1.db --output data/sector-bubble-20261020-new.html
python -B -m kiwoom_collector.sector_bubble --date 2026-10-26 --environment mock --db data/stock1.db --output data/sector-bubble-20261026-new.html
```

출력은 매번 새 HTML 경로로 지정한다. 기존 파일·심볼릭 링크는 덮어쓰지 않는다. 기본 날짜는 KST 오늘, 환경 mock, test_mode=0이다. 테스트 흐름은 `--test-mode 1`로 명시한다. qry_tp는 1로 고정하며 다른 유형 수집·결산 기능을 만들지 않는다.

운영 DB 접근은 기존 v3.report의 mode=ro + query_only + 읽기 트랜잭션과 SQLite Backup API를 재사용한다. WAL을 반영한 임시 스냅샷에서 모든 회차를 읽는다. Store·마이그레이션·API·OAuth·스케줄러를 호출하지 않는다. 현재 태그를 과거 관측에 적용하며 당시 태그 이력을 재현하지 않는다.

## 버블의 해석

- 면적은 현재 TOP20 고유 종목 수에 비례한다. 반지름은 `k × sqrt(종목 수)`이며 지도 전체에 같은 k를 사용한다. 같은 값은 같은 크기다. 개별 원을 최소/최대 값으로 잘라 면적 비율을 왜곡하지 않는다. 공통 축척을 조정해 1~20 범위의 반지름을 SVG 좌표 약 22~102 안에 둔다. 반응형 SVG는 모든 원을 같은 비율로 축소한다. 서로 다른 HTML의 최대값·화면 폭이 달라지면 축척도 달라질 수 있으므로 원 숫자를 함께 읽어야 한다.
- 빨강은 직전 성공 회차 대비 관심 종목 수 증가, 파랑은 감소, 회색은 유지다. 첫 관측이나 불완전 표본은 점선 비교 불가로 표시한다. 색상은 주가 등락률이 아니다. 기존 v3 원자료의 관측 차이는 상세에 유지하되 불완전 표본의 지도 색상 판단은 보류한다.
- 직전 0→현재 양수인 섹터는 신규 표시를 추가한다. 현재 0인 이탈 섹터는 가짜 최소 원을 만들지 않고 '현재 이탈 · 원 없음' 목록으로 제공한다. 더 이전 회차에만 있었던 섹터도 별도 펼쳐보기로 보존한다.
- 현재 관심 종목 수→TOP5→이름 순으로 최대 8개를 선택한다. 나머지 현재 섹터는 지도 밖 목록에서 상세를 선택할 수 있다. 순위 가중치·종합점수는 없다. 공간이 작은 원은 이름을 줄여 표시하며 전체 이름은 툴팁·목록·접근성 이름·상세에 남긴다.
- 지속성은 출현 n/N회, 관측 연속 횟수, TOP5 출현 횟수를 별도 상세에 표시한다. 크기나 색상에는 섞지 않는다. 분모는 성공 관측 수이며 예정 회차 수·시간 점유율이 아니다. 실제 관측 간격과 중간 미관측/미완료도 기존 v3 결과를 따른다.

배치는 섹터명 해시로 고정 셀을 배정한다. 동일한 표시 집합에서는 종목 수·색상·정렬이 바뀌어도 중심이 유지된다. 섹터가 추가·제외되거나 8개 표시 경계를 넘으면 선택 집합 및 해시 충돌 해결로 위치가 바뀔 수 있다. 위치 자체는 순위·방향 지표가 아니다. PC는 최대 4열×2행, 모바일은 2열로 압축 배치한다. 각 셀은 최대 지름보다 넓어 원이 겹치지 않는다. 애니메이션은 없다.

## 선택·상세·표 보기

버블 또는 섹터 이름 목록을 누르면 우측 상세 패널이 바뀐다. 현재 TOP20·TOP5, 직전 대비 변화, 출현·관측 연속과 소속 종목별 현재/직전 순위·진입/유지/이탈·시세/거래대금 검증 상태를 확인할 수 있다. 이탈 종목의 시세는 직전 관측임을 표시한다. hover는 간단한 툴팁만 제공한다. 작은 화면에서는 우측 패널이 지도 아래로 내려간다.

SVG foreignObject 안의 HTML label과 네이티브 radio, CSS :has()로 클릭·터치·키보드 선택을 구현했다. Tab으로 선택 영역에 접근하고 화살표로 섹터를 이동할 수 있다. JavaScript가 없으며 기존 `default-src 'none'` CSP를 유지한다. :has()를 지원하지 않는 구형 브라우저는 모든 상세와 v3 표를 표시하는 폴백을 제공한다. 최신 Chromium/Edge 기준 검증이며 다른 엔진과 보조공학 도구는 추가 검증 대상이다.

'버블맵 / v3 표 보기 / 함께 보기'는 같은 원자료의 보기 전환이다. 기존 v3 HTML 본문과 모든 표·미분류 목록·회차 흐름·시세 진단·원본·UUID 펼쳐보기를 수정 없이 포함한다. 메인 버블에서 미분류를 제외하되 하단에 수를 표시한다. 다중 태그는 섹터마다 코드 1회, 전체 TOP20은 코드 1회로 센다. 섹터 소속 합계가 전체 고유 수를 초과할 수 있다.

시세·금액 판단은 v3/v2의 최신 단일 배치·시점·필드·단위·모드·커버리지 정책을 그대로 사용한다. 검증되지 않은 금액은 0원으로 바꾸지 않으며 부분합·평균의 적용 수를 표시한다. 모의와 실전, 다른 날짜의 순위·시세, qry_tp=4 누적순위는 혼합하지 않는다. 버블 면적·색상으로 실제 주도섹터나 매수 신호를 확정하지 않는다.

## 검증

```powershell
python -B -m unittest discover -s tests -p test_sector_bubble.py -v
python -B -m unittest discover -s tests -v
git diff --check
```

면적 비율·동일값·크기 경계·비중첩·배치 안정성·증가/감소/유지/비교 불가·신규/이탈·최초 관측·과다 섹터·다중 태그·미분류·escaping·읽기 전용·출력 보호·실제 CLI를 검증한다. 설치된 Chromium이 있으면 실제 마우스/터치/키보드·표 전환·좁은 화면 텍스트를 오프라인으로 확인한다. 브라우저가 없는 환경은 해당 시나리오를 skipped로 명시한다. 운영 DB 스냅샷의 HTML·PC/모바일 캡처·보존 확인 결과는 별도 로컬 data 산출물로 남긴다.

후속 검증은 실제 사용자 가독성(5~10초 판독), 더 많은 섹터·긴 이름·최대 20종목의 실제 표시 조합, 다른 브라우저·화면 확대·스크린리더, 표시 집합 변경 시 위치 안정성, 추후 독립 검증된 거래대금 확장이다. 이번 버전은 거래대금 크기 전환·수집 확대를 구현하지 않는다.
