# STOCK1 TOP20 섹터 탐지 / TOP5 매매 후보 선정 정책

기준일: 2026-10-26. Sector Radar v2·v3와 Bubble Radar의 공통 분석 목적을 정의한다. TOP20은 주도섹터 후보 탐지, TOP5는 핵심 종목의 우선 검토에 사용하며, 거래대금·시세·주문 규모 대비 유동성을 검증한 뒤 매매 후보로 분류한다. 조회순위만으로 매수 신호·대장주·매매 적합성을 확정하지 않는다.

이번 변경은 정책 문서화다. 기존 분석·정렬·화면 문구·후보 목록 생성 코드를 변경하거나 자동 매매 후보 확정 기능을 추가하지 않는다. 운영 DB·스키마·수집 엔진·API 설정·인증정보·정기 일정은 그대로 유지한다. 새로운 종합점수·임의 가중치·임의 임계값은 도입하지 않는다.

## TOP20: 주도섹터 후보 탐지

TOP20 조회순위에서 다음 관측을 통해 시장 관심의 집중 방향을 살핀다.

- 같은 섹터 소속 종목들의 동시 출현
- 대장 후보와 후속 후보의 동반 관심
- 장중 섹터 군집의 확대·축소
- TOP20 반복 등장과 관측 지속성
- 해당 섹터에 TOP5 진입 종목이 있는지

동반 관심과 동반 가격 상승은 구분한다. 같은 섹터 종목이 함께 조회된 사실만으로 동반 상승·수급 유입을 추정하지 않는다. TOP20은 조회순위 표본이며 시장 전체의 관심·거래대금·유동성을 대표하는 분모가 아니다.

TOP5 밖의 TOP20 종목도 섹터 탐지·군집·지속성 계산에 계속 포함한다. 기본 매매 후보 검토에서는 우선순위를 낮추되 분석 데이터나 전체 섹터 목록에서 삭제하지 않는다. 관심섹터 TOP3 표시·TOP2 강조는 섹터의 화면 우선순위이며 개별 종목 TOP5 필터와 별개다.

## TOP5: 매매 후보 검토의 우선 필터

조회순위 TOP5 종목을 먼저 검토하고 다음 근거를 각각 확인한다. 항목을 합산한 점수나 TOP5 자동 매수 규칙은 만들지 않는다.

| 검토 항목 | 해석 기준 |
| --- | --- |
| TOP5 진입 여부 | 선택 회차의 조회순위 1~5위인지 확인한다. 첫 관측에서는 현재 포함 여부만 알 수 있으며 신규 진입은 비교 불가다. |
| TOP5 반복 등장 | 같은 비교 범위에서 해당 종목이 실제 성공 회차의 1~5위에 등장한 횟수다. TOP20 반복 횟수·섹터 내 TOP5 종목 수와 구분한다. |
| TOP5 유지·이탈 | 직전 성공 회차와 비교한다. 1~5위→6~20위는 TOP5 이탈이지만 TOP20 유지다. TOP20 이탈·누락·불완전 표본을 같은 상태로 처리하지 않는다. |
| 섹터 동반 상승 | 같은 섹터의 다른 종목에서 시점과 등락률 검증을 통과한 상승 관측이 있는지 확인한다. 시세 미확인은 상승 없음이나 보합으로 바꾸지 않는다. |
| 검증된 거래대금 상위권 | 단위·시점·커버리지와 비교 대상 범위가 확인된 금액 순위를 따로 확인한다. 조회순위로 대체하지 않는다. |

TOP5는 후보 검토의 출발점이다. 거래대금의 단위·시점·커버리지가 검증되지 않으면 실제 매매 후보 확정을 보류한다. 일부 관측만 유효하면 그 부분의 근거와 누락 범위를 표시할 수 있지만 전체 비교가 검증됐다고 보지 않는다. 검증 통과도 자동 매수·주문을 뜻하지 않는다.

검토 순서는 **TOP20 섹터 탐지 → TOP5 핵심 종목 우선 검토 → 거래대금·시세·유동성 검증 → 매매 후보 분류**다. 거래대금만 검증됐더라도 시세나 주문 규모 대비 유동성이 미검증이면 우선 검토 대상으로 유지하고 매매 후보 분류를 보류한다. 현재 레이더가 이 분류를 자동으로 수행하는 것은 아니다.

현재 레이더의 종목별 TOP5 출현 횟수, 현재/직전 순위와 시세·금액 진단은 검토 근거로 재사용할 수 있다. 다만 기존 신규·유지·이탈 표시는 TOP20 집합 기준이다. 이 문서화만으로 별도의 TOP5 진입·유지·이탈 표시나 매매 후보 확정 기능이 구현된 것은 아니다.

## 거래대금과 주문 규모 대비 유동성

조회순위와 거래대금은 별도 지표로 유지한다. 조회순위가 높아도 거래대금이 많다고 추정하지 않는다. 공식 단위 선언·원화 환산값과 실전 단위의 독립 검증 완료를 구분하며 기존 v2의 단위 검증 게이트를 그대로 따른다. mock 검증은 real 검증을 대신하지 않는다.

금액을 사용할 때는 같은 날짜·환경·회차·테스트 구분, 최신 단일 배치, 요청/API 시각, 종목 연결, 필드·단위·값과 적용 종목 수를 기존 규칙으로 확인한다. 누락은 0원이 아니며 다른 회차·이전 배치·다른 날짜 값으로 채우지 않는다. 장중 누적 거래대금은 관측 사이 구간 거래대금이 아니다.

향후 기능은 다음 근거를 조회순위와 분리해 다룰 수 있도록 설계한다. 이번에는 수집·계산·저장·화면을 추가하지 않는다.

- 거래대금 순위의 비교 범위(현재 TOP20 표본 또는 별도로 검증된 시장 유니버스), 기준 시각·누적/구간 기준, 적용 수·전체 수, 단위와 검증 근거를 명시한다. TOP20 내 상위권을 시장 전체 거래대금 상위권으로 표시하지 않는다.
- 주문 규모 대비 유동성은 예정 주문 금액·수량과 같은 시점의 검증된 유동성 자료를 함께 검토한다. 필요하면 호가·스프레드·잔량·실제 체결 자료 등의 확보·검증 계획을 별도로 세운다. 누적 거래대금만으로 해당 규모의 체결 가능성을 확정하지 않는다.
- 상위권의 경계와 주문 규모 대비 판단 기준은 데이터 검증 후 별도 설계한다. 현재 정책에는 임의 기준·시총 가중치·유동성 점수를 넣지 않는다.

## 대장주와 대표 종목의 구분

대장주는 단순 조회순위 1위 종목이 아니다. 해당 섹터의 시세를 주도하는지, 거래대금이 집중되는지, 후속 종목들의 동반 상승이 있는지, 관심과 수급이 지속되는지를 각각 검증해 판단한다. 조회 반복은 관심 지속의 근거이며 수급 지속의 직접 증거는 아니다. 가격 주도·수급 집중의 판정 기준과 자동 대장주 판별은 후속 설계 대상이다.

검증되지 않은 종목을 대장주로 확정하지 않는다. 대장 역할을 검토 대상으로 표현할 때는 **대장 후보**로 표시하며 미확인 근거를 함께 구분한다. 기존 화면의 **대표 종목**은 해당 섹터에서 조회순위상 먼저 표시하는 종목이다. 대표 표시만으로 대장주 검증이나 TOP5 통과·매매 후보 확정을 의미하지 않는다. TOP5에 들지 않은 섹터의 대표 종목도 존재할 수 있다. 이번에는 기존 HTML의 대표 문구나 표시 로직을 변경하지 않는다.

## 비교 범위와 보존 원칙

- 장중 기본 대상은 동일 KST 거래일·환경·qry_tp=1·운영 구분의 성공 관측이다. v2의 명시적 테스트 흐름은 기존대로 별도이며 mock/real·운영/테스트를 섞지 않는다.
- 직전 성공 회차와 비교하고 실제 시간 간격을 표시한다. 반복·지속성의 분모는 선택 시점까지 실제 관측한 성공 회차 수이며 예정 10회가 아니다. 미래 회차를 포함하지 않는다. 누락·실패·불완전 표본에서는 관측되지 않은 변화를 추정하지 않는다.
- qry_tp=4 당일 누적순위는 향후 별도 일일 결산·Sector Calendar 보조 자료다. 장중 순위와 직접 비교하거나 반복 횟수에 합산하지 않는다. 기존 장중 10회·TOP20 시세 연동·DB 스키마를 유지한다.
- 다중 태그는 섹터 내 코드 1회, 전체 TOP20은 고유 코드 1회로 센다. 섹터 합계는 전체를 초과할 수 있다. 유사 대분류·세부 섹터와 기존 바이오/제약·바이오 태그를 자동 통합하지 않는다. 미분류를 새 섹터에 임의 배정하지 않는다.
- 현재 태그를 과거 관측에 적용한 분석이라는 한계를 유지한다. 다른 날짜의 시세나 현재 시세를 과거 순위에 혼합하지 않는다.

기존 설계와 기능상 충돌은 없다. 혼동 가능성이 있던 TOP5 필터와 매수 신호, 대표 종목과 대장주, TOP5 이탈과 TOP20 이탈, 표본 거래대금과 시장 유동성의 의미를 명시했다. 기존 버전별 표시 수·정렬 차이는 유지하며 공통 정책을 이유로 코드를 변경하지 않는다.
