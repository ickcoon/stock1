# C15-11: 오전 브리핑과 종목별 표시 근거

2026-11-05 저장 자료만 재생한 개발 결과다. 운영 Collector/DB/스케줄/키는 변경하지 않았으며 API 호출, Telegram 발송, commit/push 및 배포는 하지 않았다.

## 구현 및 실행

```powershell
.venv/Scripts/python.exe -m kiwoom_collector.c15_briefing --date 2026-11-05
```

새 개발 진단 디렉터리에 시점별 Telegram 본문, 전체 diagnostics.json, 기존 source-preview.txt를 저장한다. 본문은 각각 한 메시지다. 기존 C15-7/8/9/10/10B 명령과 가중치는 유지한다. 기존 analyze_themes, 상품 제외 판정, capital_band, 검증된 ka10001 캐시 조회, 0186 대체 선택 및 거래대금 대조를 재사용한다.

변경 파일:

- `kiwoom_collector/c15_briefing.py`: 저장 분석을 재사용하는 별도 미리보기 CLI, 간결 본문/상세 진단 분리.
- `kiwoom_collector/c15_briefing_data.py`: 코드·시점·근거 검증, 시총 참고값/단위 표시, 상품 분류 보류 처리.
- `kiwoom_collector/c15_identity.py`: 선택된 과거 KRX 자료의 원본 필드 대조 결과를 기존 종목 근거에 추가. DB 쓰기 없음.
- `config/c15-display-contract.json`: 시총 표시 검증 근거. 점수 가중치 설정 아님.
- `tests/test_c15_briefing.py`, `tests/test_c15_briefing_actual.py`: 합성/실제 자료 검증.
- 이 문서 및 `diagnostics/c15-11-20261105-verified/` 결과물.

## 상품 제외와 매핑

공식 6자리 코드, 확보 시점이 확인된 KRX 분류와 기존 fingerprint 검증 Kiwoom 분류만 확정 제외에 사용한다. 충돌은 보류한다. 이름 패턴은 검토 표시만 하며 ETF/ETN/리츠/스팩으로 자동 확정하지 않는다. 우선주는 별도 보류한다. 분류 미확인 종목은 원본 관측/매핑 통계에 남기되 새 브리핑의 적격 후보 계산에서는 보류한다.

현재 확보한 KRX 주식 마스터에 ETF/ETN 전체 목록이 없고, 이전 문서에 언급된 상품 카탈로그의 검증 가능한 실제 행을 확보하지 못했다. 따라서 **실제 추가 확정 제외는 0개**다. 유형 미확인 38개를 이름만으로 제거하지 않았다. ETF 제외 문제가 모두 해결되었다고 판단하지 않는다.

| 시각 | 관측 전→상품 제외 후 | 확정 제외 전→후 | 유형 보류 | 테마 미분류 전→후 | 매핑 전→후 |
|---|---:|---:|---:|---:|---|
|09:40|103→103|0→0|38|53→53|50/103 (48.54%) 유지|
|09:45|103→103|0→0|38|53→53|50/103 (48.54%) 유지|
|09:50|105→105|0→0|38|53→53|52/105 (49.52%) 유지|

분모는 해당 시점 0198 TOP20과 선택된 0186 부분 관측의 종목코드 합집합이다. 09:45는 09:40 0186을 포함하므로 과거 0198 단독 20개 분모와 구분한다. 복수 테마 종목을 분모에 여러 번 세지 않는다. 상품 제외만 적용한 TOP3는 기존과 동일하다.

## 시총과 순위 변화

원본 `MKTCAP`, `TDD_CLSPRC`, `LIST_SHRS`와 SQLite 저장 필드를 정확 대조하고 양수 시총 = 종가 × 상장주식수인지 확인했다. 공식 [KRX 주가의 KRW 표시](https://global.krx.co.kr/contents/GLB/06/0602/0602010201/GLB0602010201T3.jsp)와 [시가총액 산식](https://global.krx.co.kr/contents/GLB/03/0305/0305010000/GLB0305010000.jsp)을 통해 원 단위 표시를 교차 검증했다. **해당 API MKTCAP 필드의 명시적인 단위 문서를 확보한 것은 아니다.** 진단에 `api_MKTCAP_unit_explicitly_documented=false`, `display_only_unit_corroboration=true`를 남긴다. 원본 market_cap_won NULL 및 미검증 상태를 덮어쓰지 않는다.

11/04 종가 자료는 11/05 11:59 이후 확보되어 오전 재생에 사용할 수 없다. 따라서 분석 전에 확보된 가장 최근 **11/03 종가 참고값**을 사용했다. 마스터 원문 파일은 없고 저장된 해시·수신 이력 및 일별 원본 행의 연결을 검증한 범위다. 시총 표시 가능 종목은 66/66/68개이며, 나머지는 미확인이다. ka10001 캐시를 기존 검증 정책으로 조회했으나 실제 캐시 0행이었다.

기존 하한은 정확히 **3,000억원 초과**다. 3,000억원과 같아도 보류하며 상한을 새로 추가하지 않았다. 기존 선호 시총 구간 함수를 재사용했다. 새 브리핑에서는 과거 종가 참고값으로도 명확히 하한 이하인 후보를 보류한다. 하한 초과가 전체 유동성/실시간 적격성 통과를 뜻하지 않는다. 시총 미확인은 적격성 보류이며 확정 주도주로 표시하지 않는다.

| 시각 | 기존 TOP3 (점수) | 상품 제외만 | 시총 하한 반영 브리핑 TOP3 (점수·상승 수) |
|---|---|---|---|
|09:40|제약바이오 57.266 / 신재생에너지 52.213 / 로봇 36.275|동일|제약바이오 57.266·5 / 신재생에너지 40.890·4 / 은행 36.137·3|
|09:45|제약바이오 58.266 / 신재생에너지 52.172 / 로봇 36.200|동일|제약바이오 58.266·5 / 신재생에너지 40.873·4 / 은행 36.137·3|
|09:50|제약바이오 57.025 / 신재생에너지 53.124 / 은행 45.238|동일|제약바이오 57.025·5 / 은행 45.238·4 / 신재생에너지 41.608·4|

시총 하한 보류는 각각 8/7/8종목이다. 예를 들어 대명에너지 약1,896억원, 대동기어 약1,003억원이 보류되며 신재생에너지/로봇 관측 기여가 줄었다. 가중치를 바꾸거나 금액 점수를 활성화한 결과가 아니다. 기존 원본 분석과 중간 단계 순위는 모두 진단에 보존한다.

## 거래대금과 미리보기

필드는 `ka10032`의 `trde_prica_upper[].trde_prica`다. 기존 [공식 명세 고정 버전](https://raw.githubusercontent.com/Kiwoom-Securities/Kiwoom-REST-API/953e5dbff123f437ab4d11a78a95191a685eb51f/kiwoom/_data/kiwoom_api_spec.json)의 백만원 단위를 적용해 원본 ÷100을 억원으로 표시한다. 저장된 페이지/행/선택 스냅샷이 일치할 때만 출력한다. 별도 네트워크 원문 응답은 확보하지 않았다. 당일 누적이라는 근거가 부족하여 누적이라고 쓰지 않고 **금액 점수 OFF**를 유지한다.

09:40 예시: 한미약품 36504→365.04억, 알테오젠 45875→458.75억, 셀트리온 95212→952.12억. 원본 변경 없음. 0186 범위 밖은 대금 미확인이며 부족 판정하지 않는다.

최종 본문:

- [09:40](../diagnostics/c15-11-20261105-verified/0940/telegram-preview.txt)
- [09:45](../diagnostics/c15-11-20261105-verified/0945/telegram-preview.txt)
- [09:50](../diagnostics/c15-11-20261105-verified/0950/telegram-preview.txt)

각 파일에 대표 3종목의 실제 저장 등락률·시총·대금, 점수/상승 수, 시총 기준일, 0198/0186 시각이 있다. 09:45는 0186 09:40 대체이고 등락률도 09:40 기준이라고 표시한다. 최신 실시간이나 신규 매수세로 해석하지 않는다. ADR20 64.24도 기존 엔진의 사후참고 표시를 유지하며 당시 이용 가능 지표인 것처럼 사용하지 않는다. 모든 결과는 잠정 관측 후보이며 확정 주도주가 아니다.

같은 폴더의 diagnostics.json에 원본 경로, 수집/저장 시각, 전체 미분류 목록, 종목별 상품 근거·시총 원본·기준일·대금 환산과 신선도, 점수 구성요소, 원본 분석과 단계별 비교를 보존했다.

## 검증

관련 회귀 포함 **220개 테스트 통과**. 신규 합성 테스트 17개, 신규 실데이터 테스트 8개이며 나머지는 기존 C15 및 연관 모듈 회귀다. 테스트 목록/결과는 `validation.json`에 기록한다.

실데이터: 세 시점 재현, 09:45 대체, 과거 KRX 확보시점 제한, 실제 수치 대조, 시총 보류에 따른 기존 점수 재계산, 원본 분석 불변, read-only SQLite URI 강제, 네트워크/발송 차단 상태 실행, 미적용 스케줄 패치 해시 불변을 확인했다.

합성: ETF/ETN/리츠/스팩 확정 분류 제외, 이름 패턴만으로 제외 금지, 미확인/충돌 보류, 기존 검증 Kiwoom 분류 재사용과 잠정 분류 거부, 미래/다른 코드/단위/원본 대조 실패 시 시총 보류, 3,000억원 경계, 시총/대금 미확인, 출력·경로 보호를 검증했다. 실데이터 상품 제외 증가를 검증한 것으로 해석하면 안 된다.

## 운영 연결 준비와 남은 문제

현재 `operating_workflow.Workflow.morning_review` → `morning_briefing.process` → 기존 Telegram 모듈 연결이 있다. 새 C15 브리핑은 **아직 해당 전달 계약에 호환되지 않는다**. 향후 승인된 작업에서 `telegram_briefing.validate/summary`에 C15 스키마의 불변 결과/본문 fingerprint 검증 분기를 추가하고, Workflow의 아침 입력 생성 지점만 C15 결과로 연결하는 것이 최소 변경안이다. 기존 수신자 allowlist, 예약/중복 방지, delivery_schema와 revision 계약을 유지해야 한다. 새 발송 클라이언트나 우회 전송을 추가하지 않는다. 이번에는 연결하지 않았다.

`diagnostics/c15-10b-20261105/runtime-schedule-proposal.diff`는 미적용 상태 그대로다. 운영 09:45 0186 추가는 별도 승인 단계다.

남은 문제: 시점 검증 가능한 ETF/ETN 전체 상품 마스터 확보, KRX MKTCAP의 API 필드 단위 명세 확보, 오전 전에 도착하는 전일 시총 자료, ka10001 검증 캐시 부재, 0186 첫 페이지 부분 수집과 누적 기준 미확인, ADR20 사후 자료, 종목별 전체 유동성 적격성 부족. 다음 단계에서는 이런 자료 계약을 보강한 뒤 운영 어댑터를 검증해야 한다.
