# Step 6-C 시가총액 및 장마감 적격성 연결

`capital_filter.integrate`는 저장된 Step 5-E JSON과 독립 ka10001 파싱 JSON만 결합한다. DB·네트워크·토큰을 사용하지 않는다. `bubble_cross --capital-json`은 선택적 연결이며 기존 입력과 버블 크기·색·정렬을 유지한다. 수집기는 변경하지 않는다.

## 단위 근거와 계산 구분

- [공식 REST JSON 명세](https://raw.githubusercontent.com/Kiwoom-Securities/Kiwoom-REST-API/main/kiwoom/_data/kiwoom_api_spec.json): mac은 억원, flo_stk 설명은 천원으로 남아 있다.
- [공식 Plugin 구현 symbol_info](https://raw.githubusercontent.com/Kiwoom-Securities/Kiwoom-Plugin/main/kw_runtime/normalize.py): flo_stk를 천 주로 설명하고 1,000을 곱한다. 명세 표기를 오기로 설명한다.
- 따라서 공식 구현의 천 주 처리 근거는 확인했지만 공식 자료 간 표기 충돌은 보존한다. 기존 파서 원본·실측 검증 플래그를 자동 변경하지 않는다.

SK하이닉스 mac 9847037억원 = 984,703,700,000,000원. 천 주 가정 시 730492×1000×1,348,000 = 984,703,216,000,000원. 차이는 484,000,000원(4.84억원)이다. 이는 조건부 산술 진단이며 허용 오차나 일치 판정을 만들지 않는다. 다른 종목의 시총을 추정하는 데 사용하지 않는다.

## 필수 하한과 탐색 구간

일반 주식의 검증된 시총 3,000억원 이상, 검증된 장마감 누적 거래대금 1,000억원 이상, 거래대금 순위 40위 이내, 섹터 동반 상승 확인을 장마감 최종 검토의 조건으로 사용한다. TOP5는 우선 검토 조건이며 필수 하한과 구분한다. 장중에는 잠정 관찰한다. ETF·ETN 등은 분리한다.

| 구간 | 용도 |
|---|---|
| 3,000억원 미만 | 시총 기본 하한 미달 |
| 3,000억원 이상~5조원 이하 | 핵심 탐색 |
| 5조원 초과~10조원 이하 | 확장 탐색 |
| 10조원 초과 | 초대형 주도주 |

탐색 구간은 잠정 전략 가설이며 절대 상한이 아니다. 5조원·10조원 초과로 섹터 탐지 또는 TOP5 관찰에서 제외하지 않는다. 점수·가중치·기대수익률을 추가하지 않는다. 구간별 행 수·최종 검토 가능 수와 종목별 순위·거래대금·등락률 원본을 보존한다. 후보 자동 확정은 하지 않는다.

검증된 구간(`capital_band`)과 미검증 참고 구간(`capital_band_reference`)을 분리한다. 오래된 값, 다른 시점의 값, 미확인 단위의 값은 현재 검증된 구간에 넣지 않는다. 후보 수는 현재 항상 0이며 검토 가능 수와 혼동하지 않는다.

## 증거 계약과 보류

종목코드 문자열을 정확히 매칭한다. 중복 시총은 격리하고 환경 혼합은 거절한다. 외부 검토 증거는 시총 레코드 fingerprint 및 교차 자료 context hash에 결속한다. 증거는 엔진 자체가 인증하는 것이 아니며 검토된 출처만 주입해야 한다. 증거 없는 실제 자료는 항상 보류한다.

시총·거래대금의 시세 기준시각과 거래일, 일반 주식 유형, 단위·시장 조건·장마감 누적 기준·섹터 동반 상승을 별도로 확인한다. 0198/0186 수집 시차 300초 조건은 잠정 비교일 뿐 실제 시장 시각의 검증을 대체하지 않는다. 과거 화면에 미래 거래대금·시총을 적용하지 않는다. `candidate_confirmed=false`를 항상 유지한다.

2026-10-27 15시 교차 자료에 16:46 SK하이닉스 시총을 역사적 적격성으로 적용하지 않는다. 해당 종목에 별도 조회시각만 참고 표시하고 나머지 종목의 시총은 미확인으로 유지한다.

전체 회귀는 운영 DB·.env 접근과 외부 네트워크를 차단한 격리 소스 사본에서 실행한다. 실제 데이터 보고서는 저장된 JSON만 읽어 생성한다. 추가 API/OAuth 및 커밋·push는 수행하지 않는다.
