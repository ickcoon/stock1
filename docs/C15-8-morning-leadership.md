## 점수와 판정

설정은 `config/c15-leadership.json`에 분리했다. 모든 가중치는 **초기 가설값**이며 수익성·최적 전략 검증을 뜻하지 않는다. 기존 엔진의 동반 상승 최소 2종목 원칙을 유지한다.

테마 안에서 코드별 1회 집계한다. 명시적 제외 상품·검증된 시총 기준 미달 종목은 상승 기여에서 빠진다. 양수 보고 등락률이 있는 종목만 점수·대표 관측 후보에 기여한다. 미확인 등락률은 0%로 채우지 않는다.

테마 수를 `m_i`, 양수 보고 상승률을 `r_i`, 조회순위를 `q_i`, 상승 관측 종목 수를 `n`이라 할 때:

```
breadth  = 10 * n
strength = sum(min(r_i, 10) / m_i) / n
attention = sum((21 - q_i) / 20 / m_i)  # 조회 TOP20 내 상승 종목만
cross = sum(1 / m_i)                    # 0198과 동일 슬롯 0186 교차 상승 종목만
score = breadth + strength + attention + cross
```

**동반 상승 종목 수 내림차순 → 점수 내림차순**으로 순서를 정한다. 이후 완전히 같은 경우에만 기존 엔진이 검증한 누적 거래대금을 비교한다. 단일 상승 테마는 점수가 높아도 `low_single_stock`으로 보류한다. 하락만 있는 테마는 선정하지 않는다. 급등률은 10%에서 점수 기여를 제한하되 출력에는 실제 보고 상승률을 표시한다.

대표 관측 후보는 기존 적격성 충족 여부 → 제한된 상승 강도 → 조회순위 → 확보된 거래대금순위 → 검증 금액 순으로 최대 3개를 선택한다. 부족하면 채우지 않는다. 시총·상품·유동성 근거가 부족하면 후보마다 **미확인·보류**를 표시하며 확정 주도주로 승격하지 않는다.

복수 테마 종목의 상승 수는 각 테마에서 1회씩 세지만 강도·관심·교차 점수 기여를 테마 수로 나눈다. 테마별 상승 수를 더해 시장 고유 종목 수로 표현하지 않는다. 복수 소속 종목을 뺀 고유 상승 종목 수 순서도 민감도 참고로 별도 출력한다. 이것은 모든 종목을 제거해 전체 점수를 재계산한 결과가 아니라 고유 동반 상승 수의 비교다.

거래대금 단위 증거가 현재 없으므로 **금액 점수 적용 없음**. 0186 순위를 전체 시장 순위나 미관측 종목의 낮은 순위로 해석하지 않는다. ADR20은 선정 조건·점수에 포함하지 않는다.
